✅ What You're Doing Well

Layered content moderation
Hard-block regex runs locally first (zero latency, no API cost) then the AI catches nuanced edge cases. Two-stage is the right architecture — it's what production content platforms use.
Idempotent Stripe webhook handling
Using upsert({ onConflict: 'email' }) means Stripe webhook retries never create duplicate customers or double-charge. Critical for payment reliability and you got it right.
Correct Stripe webhook signature verification
stripe.webhooks.constructEvent(req.body, sig, secret) with express.raw() before JSON middleware — textbook correct. Many tutorials get this wrong. You didn't.
Semantic cache with filler-word normalization
"please help me clean the bathroom" and "clean bathroom" hit the same cache entry. Smart, reduces AI costs significantly, and the optional embedding fallback is a nice upgrade path.
Supabase auth client stubs out gracefully
The supabase.js client returns a no-op stub when env vars are missing. The app still works without auth configured — excellent DX for development and onboarding new contributors.
requireAuth middleware on all protected routes
Clean separation — every route that needs auth explicitly declares it. No route accidentally forgets the middleware. The pattern makes security review straightforward.
System prompt quality
The ADHD-specific constraints (no should/must, one action per step, specific sensory detail) are well-thought-out and make a real difference in output quality. The product lives its values in the prompt.
USE_LOCAL_LM toggle for offline development
The callAI() abstraction lets you develop without burning Anthropic credits. The LM Studio integration is clean and the model swap is truly seamless.
